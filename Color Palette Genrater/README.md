# Random Color Generator

This is a simple website that makes a palette of 6 random colors for you to use. It's built with basic HTML, CSS, and JavaScript.

## What It Does

- **Get New Colors**: Click the "Generate" button to see 6 new random colors.
- **Copy Colors**: Click any color box or its copy icon to copy the color code to your clipboard.
- **See It Copy**: The icon changes to a checkmark so you know it copied successfully.

## Tools Used

- HTML, CSS, and JavaScript
- Font Awesome (for the copy icons)

## How to Use It

1. Open the `index.html` file in your web browser.
2. Click the "Generate" button to get new colors.
3. Click on a color to copy its code!
